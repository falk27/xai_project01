# XAI Project 1

## Project

We compare models that process time-series data in the time domain with models that process the same data in the frequency domain. We use ECG200 and FreezerRegularTrain for this comparison.

## Repository structure

- `01_Course_Materials/` contains the assignment, course demonstration, and provided starter files.

## Collaboration

We work on separate branches for project tasks. Changes are proposed and reviewed through pull requests before they are merged into `main`.
